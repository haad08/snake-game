# Snake

A classic Snake game, built as a single self-contained web page — no installs, no build tools, no dependencies beyond a Google Font.

## Play it

Just open `index.html` in any browser. Or, once hosted (e.g. via GitHub Pages), visit the live link: *[add your live URL here once deployed]*

## Controls

- **Arrow keys** or **WASD** — move
- **Space** — pause/unpause
- On touch devices, on-screen arrow buttons appear automatically

## Features

- Classic grid-based Snake gameplay with wall and self-collision
- Score tracking, with a running "best score" for the session
- Speed increases slightly as your score grows
- Retro arcade visual theme (neon green on dark background, pixel-style font)
- Fully responsive — playable on desktop or mobile

## Tech

Built with plain HTML, CSS, and JavaScript using the HTML5 `<canvas>` element — no frameworks, no npm install, just open the file in a browser.

## Notes

- Score/best score reset on page refresh — everything runs in-memory, nothing is saved between sessions.
